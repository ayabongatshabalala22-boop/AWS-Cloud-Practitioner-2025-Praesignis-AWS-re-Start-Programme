# 🤖 Project 3: Amazon Lex Chatbot

This project was completed collaboratively with four other candidates in the program, focusing on creating an interactive chatbot using **Amazon Lex**, an AWS service designed for building conversational applications.  

The goal was to understand how chatbots work and how they can be used as effective learning tools. The project was completed in two parts:  
1. Building a simple chatbot to understand the basics of Amazon Lex.  
2. Expanding the chatbot into an interactive quiz designed for learners.  

The chatbot was created for a fictional educational company, **CloudLearners Inc.**, which wanted an engaging way to test learners’ knowledge of **Amazon S3**. We created and deployed the chatbot, then presented it to CloudLearners Inc.  

Through this project, I gained practical experience in **chatbot design**, **user interaction flow**, and **presenting technical solutions to non-technical audiences**.

---

##  Key Project Objectives

The main objective was to design and deploy a functional chatbot using Amazon Lex. The chatbot needed to understand user input, respond appropriately, and guide users through an interactive experience.

**Additional objectives included:**
1. Learning how to configure and manage a chatbot in Amazon Lex  
2. Creating intent-driven conversations using utterances and responses  
3. Designing a simple knowledge quiz with customized logic  
4. Providing clear feedback for both correct and incorrect user responses  
5. Demonstrating the chatbot through a live presentation and explaining its functionality clearly  

---

## 🛠️ Process Outline – Tasks Carried Out

The project began by accessing the **AWS Management Console** and navigating to Amazon Lex. A new chatbot was created using the **English (ZA)** language setting with basic configuration options to focus on learning core concepts. The project was addressed in two parts:

### Part 1
- Created a single intent related to **Amazon S3**  
- Defined one user utterance and linked it to a clear, informative response  
- Learned how Lex matches user input to intents and delivers responses  

### Part 2
- Expanded the chatbot to include a **quiz feature**  
- Created a new quiz intent with multiple utterances allowing users to start the quiz  
- Designed quiz questions around **Amazon S3 concepts** with multiple-choice answers  
- Implemented branching logic to identify correct vs incorrect answers and respond accordingly  
- Integrated **AWS Lambda** using a hook to connect custom logic with Amazon Lex

## 🧪 Testing the Chatbot

Testing played a major role throughout the development process.  
The chatbot was tested using different inputs to ensure it responded correctly in all scenarios and that the quiz flow remained smooth and user-friendly.

### Key Testing Activities
- **Input validation**: tried various user utterances to confirm Lex correctly mapped them to intents.  
- **Quiz flow checks**: ensured branching logic guided users through questions seamlessly.  
- **Error handling**: tested unexpected inputs to verify the chatbot provided helpful fallback responses.  
- **User experience review**: evaluated clarity of responses and overall conversational flow.  
- **Presentation testing**: rehearsed the demo to confirm the chatbot worked reliably in front of a non-technical audience.
