AWS Tech Stack Utilized
The project leveraged several key AWS services, primarily within the free tier or at minimal cost:
Frontend Hosting: Amazon S3 (static website) & Amazon CloudFront (CDN for speed) ⚡
Networking: Route 53 (DNS) & AWS Certificate Manager (Free SSL) 🔒
Backend Logic: API Gateway, AWS Lambda (backend logic), DynamoDB (database) 
Identity/Auth: Amazon Cognito (User registration/login) 🔑
Mapping: Amazon Location Service (Interactive map) 🗺️
Key Takeaways You Highlighted
Your project demonstrated several core principles of modern cloud architecture:
Serverless Efficiency: Full dynamic functionality was achieved without managing traditional servers. ☁️
Cost-Effectiveness: Serverless architecture proved incredibly cheap for small-to-medium traffic volumes. 💸
Scalability & Security: AWS handles essential non-functional requirements like scaling, backups, and security out-of-the-box. 🛡️
Business Impact: Small businesses in SA can significantly improve efficiency and compete better by moving their operations to the cloud. 📈
