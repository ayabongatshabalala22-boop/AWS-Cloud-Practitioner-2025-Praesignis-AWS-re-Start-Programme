## 🛠️ AWS Tech Stack Utilized

The project leveraged several AWS services, mostly within the free tier or at minimal cost:

- **Frontend Hosting:** Amazon S3 (static site) + Amazon CloudFront (CDN) ⚡  
- **Networking:** Route 53 (DNS) + AWS Certificate Manager (Free SSL) 🔒  
- **Backend Logic:** API Gateway + AWS Lambda + DynamoDB  
- **Identity/Auth:** Amazon Cognito 🔑  
- **Mapping:** Amazon Location Service 🗺️  

---

## 💡 Key Takeaways

- **Serverless Efficiency:** Full dynamic functionality without managing traditional servers ☁️  
- **Cost-Effectiveness:** Serverless architecture is ideal for small-to-medium traffic volumes 💸  
- **Scalability & Security:** AWS handles scaling, backups, and security out-of-the-box 🛡️  
- **Business Impact:** Cloud migration can help SA small businesses compete and thrive 📈
