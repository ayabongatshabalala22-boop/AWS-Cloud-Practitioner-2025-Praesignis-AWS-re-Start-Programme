###  AWS re/Start Programme – Cloud Practitioner Journey
Welcome to my **AWS Cloud Practitioner 2025** repository!  
This space documents my learning journey through the **Praesignis AWS re/Start Programme**, where I built foundational knowledge and hands‑on skills in cloud computing on **Amazon Web Services (AWS)** as an entry point into the world of **cyber security** and **Data Analyst**to Excelle.

---


## 📚 What You'll Find in This Repository
- Notes and resources from AWS re/Start lectures and labs  
- Study materials and summaries on cloud computing concepts  
- Projects, scripts, and exercises demonstrating AWS usage  
- Certificates and badges showcasing my achievements  
- Reflections and milestone updates as I progress  


##  Goals

- Achieve **AWS Certified Cloud Practitioner (CLF‑C02)**  
- Gain a strong understanding of AWS core services (EC2, S3, IAM, Lambda, VPC, etc.)  
- Master cloud deployment, operations, and best practices  
- Build a solid technical foundation for a career in **Cyber Security**  
- Grow my professional network by collaborating with peers and IT professionals  

---

## 🔒 Cyber Security Aspirations

- Transition into a cyber security role focusing on **cloud security**  
- Learn to identify and mitigate cloud security risks and vulnerabilities  
- Gain hands‑on skills in **threat detection**, **incident response**, and **compliance**  
- Stay up‑to‑date with evolving security standards and best practices  
- Work towards advanced AWS and security certifications  
  - AWS Security Specialty  
  - CompTIA Security+  
  - And more as I progress  

## 📊 Data Analyst Aspirations

- Develop strong skills in **data cleaning, transformation, and visualization**  
- Learn to work with tools such as **Excel, SQL, Python (Pandas/NumPy), and Power BI/Tableau**  
- Build the ability to **interpret data**, identify trends, and support decision‑making  
- Gain hands‑on experience with **datasets, dashboards, and reporting workflows**  
- Strengthen understanding of **data governance, quality, and ethical data handling**

  - Microsoft Power BI Data Analyst
