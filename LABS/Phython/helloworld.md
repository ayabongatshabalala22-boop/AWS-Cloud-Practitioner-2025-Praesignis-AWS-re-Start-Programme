🟩 Hello World Lab (Beginner-Friendly)

This lab introduces the most basic concept in programming: printing “Hello, World!”
It helps beginners understand how programs execute, how output works, and how to run simple code in different environments.

🎯 Lab Objectives

Learn how to write your first program

Display “Hello, World!” using a programming language of your choice

Run your code from the terminal or code editor

Understand basic input/output behavior

🛠️ Lab Steps
1️⃣ Choose Your Programming Language

You can use any one of the following:

Python

JavaScript

Java

C

Bash

Go

Node.js

Any language you prefer

Below are examples for the most common languages.

2️⃣ Write “Hello, World!” Code
🐍 Python Example
print("Hello, World!")


Run:

python hello.py

🌐 JavaScript (Node.js)
console.log("Hello, World!");


Run:

node hello.js

☕ Java Example
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}


Compile & run:

javac HelloWorld.java
java HelloWorld

🖥️ C Example
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}


Compile & run:

gcc hello.c -o hello
./hello

🐧 Bash Script
echo "Hello, World!"


Run:

bash hello.sh

🔍 What to Observe

Your terminal or program output should display:
Hello, World!

Every language uses a different syntax, but the result is the same

This is the foundation of all programs: sending output to the screen

📘 Takeaways

You learned how to write your first program

You ran code using a terminal or editor

You saw how different languages print output

You understand the basic program execution flow

You now know the simplest building block of software development

⚠️ Challenges Encountered
1️⃣ Wrong File Name or Extension

Examples:

hello.pyy instead of hello.py

Helloworld.java but class named HelloWorld

2️⃣ Missing Runtime

Example: running python when only python3 is installed.

3️⃣ Permission Errors (Bash)

Not marking script as executable.

4️⃣ Incorrect Commands

Running node hello.py instead of python hello.py

🧩 Solutions
✔ Check File Names

Match the class name, filename, and extension correctly.

✔ Check Installation

Verify:

python3 --version
node --version
javac --version

✔ Fix Bash Permissions
chmod +x hello.sh

✔ Use Correct Commands

Each language has its own way of running code.
