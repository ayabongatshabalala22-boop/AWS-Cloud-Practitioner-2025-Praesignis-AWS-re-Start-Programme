## Hello World Lab (Beginner-Friendly)

This lab introduces the most basic concept in programming: printing **“Hello, World!”**  
It helps beginners understand how programs execute, how output works, and how to run simple code in different environments.

---

##  Lab Objectives

By the end of this lab, you will be able to:

- Learn how to write your first program  
- Display **“Hello, World!”** using a programming language of your choice

## 📘 Takeaways

- You learned how to write your first program  
- You ran code using a terminal or editor  
- You saw how different languages print output  
- You understand the basic program execution flow  
- You now know the simplest building block of software development  


## 🧩 Challenges Encountered

- Wrong file name or extension  
- Missing runtime  
- Permission errors (Bash)  
- Incorrect commands  

## 🧩 Solutions

- Check file names  
- Match class name, filename, and extension correctly  
- Check installation  
- Verify with: `python3 --version`, `node --version`, `javac --version`  
- Fix Bash permissions → `chmod +x hello.sh`  
- Use correct commands
