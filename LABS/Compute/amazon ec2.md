# ☁️ AWS EC2 Lab

## 📖 Overview
This lab walks you through launching, configuring, and deploying a simple web app on an **Amazon EC2 instance**. It’s designed for cloud practitioners who want hands‑on AWS experience.

---

## 🎯 Learning Objectives
- Understand EC2 concepts: instances, AMIs, security groups, key pairs.
- Launch and connect to an EC2 instance.
- Deploy a basic web application.
- Manage the instance lifecycle (start, stop, terminate).
